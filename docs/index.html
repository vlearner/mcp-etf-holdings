ETF Holdings

An MCP server for ETF data. Ask which funds hold a stock, compare fees, or pull top holdings. Data comes live from Yahoo Finance by default, with no API key, or from your own data source.

GitHub PyPI Changelog Issues

Install

Nothing to install first. Each config launches the server on demand with uv (uvx), in its own isolated environment. Needs Python 3.11+.

claude mcp add etf-holdings -- uvx mcp-etf-holdings
{
  "mcpServers": {
    "etf-holdings": {
      "command": "uvx",
      "args": ["mcp-etf-holdings"]
    }
  }
}

Add to claude_desktop_config.json (macOS: ~/Library/Application Support/Claude/, Windows: %APPDATA%\Claude\), then fully quit and reopen Claude Desktop.

{
  "servers": {
    "etf-holdings": {
      "type": "stdio",
      "command": "uvx",
      "args": ["mcp-etf-holdings"]
    }
  }
}

Save as .vscode/mcp.json, or run MCP: Open User Configuration for a global setup. VS Code uses the key servers, not mcpServers.

{
  "mcpServers": {
    "etf-holdings": {
      "command": "uvx",
      "args": ["mcp-etf-holdings"]
    }
  }
}

Save as .cursor/mcp.json for one project, or ~/.cursor/mcp.json for all of them. Restart Cursor.

What you can ask

Search by company name or ticker. "Which ETFs hold Nvidia?" works the same as "Which ETFs hold NVDA?".

AskTool
Which ETFs hold NVDA?find_etfs_holding_stock
What's the cheapest ETF for Nvidia exposure?stock_exposure_summary
Compare SPY, VOO, QQQ and SCHDcompare_etfs
What are SPY's top holdings?etf_holdings
What is QQQ's expense ratio and AUM?etf_info
Find me semiconductor ETFssearch_etfs
What's the ticker for Berkshire Hathaway?lookup_symbol

Try these

Compare SPY, VOO, IVV and SPLG. They all track the S&P 500, so which is cheapest?
I own VOO, QQQ and VGT. Am I doubling up?
Find semiconductor ETFs and compare the three biggest.

There are also five prompt templates (etf_deep_dive, compare_funds, stock_exposure, portfolio_checkup, theme_explorer) that show up as slash-commands in Claude Desktop and Claude Code.

Optional: HTTP

stdio is the default and what every config above uses. To serve over streamable HTTP instead:

uvx mcp-etf-holdings --transport http   # http://127.0.0.1:8000/mcp

It binds to loopback and has no authentication. Don't expose it beyond your own machine without an authenticating proxy. See the README for the details and a Docker example.

Know the limits

  • Only the top ~10 to 15 positions per ETF are published, so anything derived from holdings (reverse lookups, exposure, overlap) is a floor, not the full picture.
  • The default search covers about 365 funds. A stock held only in small or niche ETFs may not turn up.
  • Responses are cached for 24 hours. Yahoo's terms and rate limits apply.
